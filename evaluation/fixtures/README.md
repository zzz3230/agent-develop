# Офлайн-корпус для проверки М2

`tasks/` содержит 31 отдельное условие: 8 исходных примеров, 8 более сложных
разработческих задач, 8 новых контрольных условий, 2 задачи без достаточных
данных и 5 дополнительных экспериментальных условий (`new_*`, `sql_*`).
Основная регрессионная серия использует первые 26 условий, дополнительные
пять сохранены для воспроизведения экспериментов с моделями/SQL.
`private_checks/` — дополнительные coding-проверки, которых агент не видел.

Корпус содержит эталоны только для локальной оценки. **Весь каталог
исключён из Docker build через `.dockerignore`.** Перед запуском копировать
рабочие задачи и удалять `expected`, сохраняя `check`. Не монтировать
эталоны и приватные проверки в контейнер агента. Приватные тесты запускаются
проверяющим в отдельном контейнере после завершения попытки.

Разработческий и контрольный наборы синтетические, не тесты организаторов.
Контрольные условия созданы после настройки основных изменений; это лишь
8 новых условий, а не независимая оценка всего финального распределения.
Повторы прежних условий оценивали стабильность, не разнообразие.

Из корня репозитория проверить сохранённый run с `tasks/` и `logs/`:

```sh
python -m evaluation.validate_run --run PATH_TO_RUN --image agent-develop:m2-limits-final
```

Для `unavailable` проверяется отсутствие выдуманного ответа. Награды за
такие случаи в отчёт о конкурсных баллах не включаются. Строки сравниваются
строго после удаления внешних пробелов; это локальный диагностический
проверяющий, точный алгоритм скрытой проверки организаторов неизвестен.
