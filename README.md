# НГУ AI Hackathon — модуль 1

Запуск готового агента openJiuwen в условиях конкурса: прокси, штатные инструменты, общий бюджет, запись ответов.

- `docs/rules.md` — правила и открытые вопросы (AGE-5)
- `docs/strategy.md` — выводы из ответов организаторов и план до дедлайна
- `docs/ideas.md` — непроверенные идеи и как их проверить
- `docs/gaps.md` — что берём готовым, что настраиваем, где адаптер (AGE-22)
- `docs/interfaces.md` — стыки модулей
- `docs/examples-validation.md` — проверка примеров и результатов AGE-8/AGE-9
- `docs/model-comparison.md` — реальные сравнения моделей и наборов инструментов
- `docs/model-stability.md` — по 10 повторов каждой задачи на двух моделях
- `docs/prompt-economy-ab.md` — A/B-тест инструкции экономить токены
- `docs/task-prompts.md` — рабочий выбор инструкций и проверка более сложных задач
- `docs/sql-experiment.md` — экспериментальные CSV_SCHEMA и CSV_SQL, сравнение на прокси
- `docs/age-13-23.md` — актуальные лимиты, остановки, улучшение поиска/CSV и итоговые проверки
- `docs/adaptive-limits.md` — актуальные адаптивные лимиты, бюджет прокси и состав тестов

По умолчанию CSV получает схему, а поиск — ограниченный локальный контекст.
Лимиты по типам находятся в `runtime/attempt_policy.py`. Для отключения
подготовки: `CSV_SCHEMA=0`, `SEARCH_CONTEXT=0`; SQL остаётся выключенным.
Офлайн-корпус с эталонами — только в `evaluation/fixtures`, в Docker он не входит.

Общую токенную квоту контролирует прокси. BUDGET — локальная оценка,
которая сама не останавливает конкурсный запуск. Стартовый предел задачи
может увеличиться по наблюдаемому прогрессу до потолка её профиля.

## Сборка и запуск

```bash
docker build -t hack:latest .
```

Запуск — командой из `docs/rules.md`. Нужны `LLM_BASE_URL` и `LLM_API_KEY`; `BUDGET` необязателен, по умолчанию 100000.

## Проверка без ключа

`evaluation/mock_llm.py` заменяет прокси и записывает всё, что отправляет фреймворк. `evaluation/spike_oj.py` сравнивает конфигурации агента, `evaluation/check_limits.py` показывает, что реально блокируют штатные ограничения.

Расход и итоги пишутся в stderr и в `/tmp/harness/trajectory.jsonl`.
