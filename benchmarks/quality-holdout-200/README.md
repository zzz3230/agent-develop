# Новые 200 задач из отложенных групп

200 параметризованных экземпляров из 39 отложенных групп набора
quality-minilm. По 50 задач каждого типа, 40 невыполнимых. Награды —
независимые случайные целые 1–10. Seed содержимого 20261115, наград 20262105.
Эти группы не использованы при обучении двух quality_minilm-предикторов.
Это варианты известных алгоритмов, а не 200 независимых новых алгоритмов;
сами исходные наборы уже известны команде, поэтому это не слепой внешний тест.

Агенту монтировать **только input**. Manifest и references содержат ответы,
признаки выполнимости, эталоны исправлений и скрытые проверки; они остаются
у проверяющего. Каждый агент получает свежую копию входов. Токенные лимиты,
порядок, награды, модель и инструменты фиксируются для обоих вариантов.

Проверка метаданных и отсутствия пересечений:

```powershell
python -m evaluation.validate_quality_holdout benchmarks/quality-holdout-200 benchmarks/quality-minilm/manifest.json
```

С `--coding` дополнительно проверяются все 40 решаемых эталонных исправлений
кода. Команду нужно выполнять в Linux-окружении агента с его библиотеками.
Остальные эталоны берутся из исходных генераторов; целочисленные математические
варианты меняют требуемый ответ на q + offset. Генерация и описание разбиения:
`evaluation/quality_dataset.py`, `benchmarks/quality-minilm/README.md`.
