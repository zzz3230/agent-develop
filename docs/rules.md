## Запуск

```
docker run --rm --network hack-net -e LLM_BASE_URL -e LLM_API_KEY \
  -v "$TASKS:/data/tasks:rw" --read-only --tmpfs /tmp:rw,size=2g -e HOME=/tmp \
  --cap-drop ALL --security-opt no-new-privileges \
  --cpus 8 --memory 16g --pids-limit 512 --workdir /app --entrypoint python \
  hack:latest /app/run_agent.py --tasks-dir /data/tasks
```

## Открытые вопросы к организаторам

Отправляет участник команды. Ниже рабочие допущения на время ожидания.

1. **Точный дедлайн сдачи?** В памятке только конец доступа: 20.11.2026 23:59:59 МСК. Допущение: сдаём 19.11.
2. **Будет ли `BUDGET` передан в контейнер?** В команде запуска есть только `-e LLM_BASE_URL -e LLM_API_KEY`. Допущение: если переменной нет, бюджет 100000.
3. **Лимит CPU: 4 или 8?** В таблице регламента 4, в команде `--cpus 8`. Допущение: тестируем на 4.
4. **С какими правами монтируется `$TASKS`?** С `--cap-drop ALL` root не пишет в файлы другого владельца; `chmod 777` в команде есть только для `$OUT`. Проверено: при владельце uid 1000 и правах 755 не создаётся ни один `answer.txt`. Просим подтвердить, что каталог доступен на запись.
5. **Как проверяется обязательное использование openJiuwen?** Засчитывается ли решение, где часть задач решается кодом без вызова агента OJ?
6. **Нужен ли файл из `OUT`?** Регламент упоминает `OUT` и файл решений, но команда запуска их не передаёт. Допущение: оцениваются только `answer.txt`.
7. **Для `coding` проверяются изменённые файлы в `workspace/`?** На эту часть вопроса ответа не было. Допущение: да, правим `workspace/mylib.py` на месте.
