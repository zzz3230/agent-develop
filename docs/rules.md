# Правила конкурса (AGE-5)

Источники: `Регламент соревнования.md`, `Ответы_на_вопросы.txt` (включая вторую часть с ответами из чата), памятка НГУ. Статус на 9 ноября.

Часть ответов дана коротко и в чате. Спорные формулировки приведены дословно.

## Запуск

```
docker run --rm --network hack-net -e LLM_BASE_URL -e LLM_API_KEY \
  -v "$TASKS:/data/tasks:rw" --read-only --tmpfs /tmp:rw,size=2g -e HOME=/tmp \
  --cap-drop ALL --security-opt no-new-privileges \
  --cpus 8 --memory 16g --pids-limit 512 --workdir /app --entrypoint python \
  hack:latest /app/run_agent.py --tasks-dir /data/tasks
```

## Открытые вопросы к организаторам

Ниже рабочие допущения на время ожидания.

1. **Будет ли `BUDGET` передан в контейнер?** В ответах сказано, что будет, но в команде запуска его нет. На вопрос о бюджете в отборе и финале ответа нет. Допущение: если переменной нет, бюджет 100000.
2. **Лимит CPU: 4 или 8?** На вопрос о параметрах контейнера ответ «?». Допущение: тестируем на 4.
3. **Назначение `OUT`.** Вопрос задан, ответа нет. Допущение: оцениваются только `answer.txt`.
4. **Можно ли сменить модель на повторной попытке той же задачи?** Допущение: нет, одна задача — одна модель.
5. **Разрешены ли локальные нейросети?** Допущение: нет, пока нет письменного подтверждения.
6. **Списываются ли токены за вызов с ошибкой?** Ответ «(подумают)». Допущение: да.
7. **Считается ли весь контекст заново после вызова инструмента?** Ответ неуверенный. Допущение: считается, но перерасход не страшен: см. `strategy.md`.
8. **Как именно сравниваются строки?** Обещано уточнить. Допущение: strip и lowercase.
