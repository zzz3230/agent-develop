# Готовые возможности OJ и пробелы (AGE-22, черновик М1)

openjiuwen 0.1.19, Python 3.12. Запуски шли под флагами конкурса. Таблица служебных расходов и проверка ограничений сделаны на подставном API, раздел «Запуск на настоящем прокси» — на прокси NeuralDeep.
Строки по М2 (AGE-8, 9) и М3 (AGE-10) дополняют их владельцы.

Статусы: **код** — найдено в исходниках, **запуск** — проверено запуском, **нет** — ещё не проверено.

## Сколько стоит служебный текст агента

Одна простая задача, два запроса (`bash`, затем ответ). Ответ модели на подставном API почти пустой, поэтому в таблице в основном служебные расходы. Настоящий ответ модели добавится сверху.

| Конфигурация | Запросов | Символов инструментов на запрос | Стоимость |
| --- | --- | --- | --- |
| DeepAgent, настройки по умолчанию | 3 | 13 297 | ≈ 769 |
| DeepAgent, `prompt_mode=minimal`, без проб и rails | 2 | 13 297 | ≈ 716 |
| ReActAgent, 6 штатных инструментов | 2 | 12 683 | ≈ 685 |
| ReActAgent, 6 инструментов, короткие описания | 2 | 2 300 | ≈ 166 |
| ReActAgent, `bash`, read, edit, короткие описания | 2 | 1 151 | ≈ 109 |
| ReActAgent, только `bash`, короткие описания | 2 | 465 | ≈ 75 |

При среднем бюджете 1000 на задачу описания инструментов — главный расход. Описание `bash` занимает 7191 символ из 12 683.

Сокращение делается настройкой `card.description` и `input_params` штатных инструментов.

**Выбор: ReActAgent с сокращёнными описаниями.** DeepAgent дороже и создаёт 21 служебный файл в рабочей папке (`AGENT.md`, `memory/`, `todo/` и другие), поэтому его рабочую папку нельзя совмещать с папкой задачи.

## Запуск на настоящем прокси

`qwen3.8-27b-noreason`, ReActAgent, `bash` (в `coding` ещё read и edit), короткие описания, задачи по порядку, 6 шагов максимум. 8 примеров заняли 70 секунд.

| Тип | Решено | Средняя стоимость |
| --- | --- | --- |
| math | 2 из 2 | 173 |
| data_analysis | 2 из 2 | 304 |
| search | 2 из 2 | 366 |
| coding | 1 из 2 | 977 |
| Всего | 7 из 8, 18 из 20 баллов | 3640 на 8 задач |

`coding_0007` израсходовала все 6 шагов, тесты остались красными; ложного `DONE` нет. Разбор причин — AGE-9.

Сравнение на одной задаче со складом:

| Конфигурация | Вызовов | Стоимость | Ответ |
| --- | --- | --- | --- |
| DeepAgent минимальный | 1 | 375 | 1561, посчитан в уме, без `bash` |
| ReActAgent, 6 инструментов | 1 | 366 | 1561, посчитан в уме, без `bash` |
| ReActAgent, `bash`, короткое описание | 2 | 138 | 1561, через `bash` |
| То же, `qwen3.6-35b-a3b-noreason` | 2 | 139 | 1561, через `bash` |
| То же, `qwen3.8-27b` с рассуждениями | 1 | 88 | **пустой ответ**, один запуск, причина не выяснена |

Формат `usage` у прокси: `prompt_tokens`, `completion_tokens`; `reasoning_tokens` входят в `completion_tokens` (63, из них 57), так что двойного счёта нет. У `qwen3.6-35b-a3b` поля `reasoning_tokens` нет, но `completion_tokens` тоже отражает рассуждения (246 токенов на ответ из трёх цифр). Прокси не сообщает общий расход, поэтому сверка возможна только по `usage` каждого ответа.

## Требования конкурса

| Требование | Компонент OJ | Статус | Решение |
| --- | --- | --- | --- |
| Цикл агента | `ReActAgent`, `create_deep_agent` | запуск | берём готовое |
| Python и файлы | `BashTool`, `ReadFileTool`, `EditFileTool` и др. | запуск | берём готовое, настраиваем описания |
| Работа в read-only | создаёт `logs/` в текущей папке | запуск | настройка: `chdir` в `/tmp` до импорта OJ |
| Пробный запрос с картинкой | `enable_read_image_multimodal` | запуск | настройка: выключить (≈ 20 токенов на агента) |
| Границы файлов | `restrict_to_sandbox`, `sandbox_root` | запуск | работает для файловых инструментов |
| Границы shell | `shell_allowlist` | запуск | **частично**, см. ниже |
| Защита тестов | нет | запуск | **адаптер**: снимок и восстановление, попытка не засчитывается |
| Ключ не виден агенту | shell наследует окружение | запуск | **адаптер**: `os.environ.pop` до старта агента |
| Общий бюджет `input/10 + output` | `TokenBudgetEvaluator` | код | **адаптер `MeteredModel`**: штатный считает сырые токены и только во внешнем цикле |
| Потерянный `usage` | нет | запуск | в адаптере: оценка по длине, запрос не бесплатный |
| Формат задач, `answer.txt` | нет | запуск | **адаптер** `runtime/tasks.py`, запись атомарная |
| Сохранность при `docker kill` | — | запуск | готовые ответы целы, временных файлов нет |
| Остановка при отказе прокси | — | запуск | свой счётчик ошибок: 4 подряд |
| Лимит времени на задачу | `asyncio.wait_for` | код | штатные `TimeoutEvaluator` относятся к внешнему циклу |
| Ограничение вывода команд | `BashTool`, вывод > порога уходит в файл | запуск | берём готовое |
| Таймаут команды | `BashTool` | запуск | берём готовое |
| Выбор задач | `TaskPlanningRail` ведёт шаги, не очередь | код | М3 |
| Повторы 429/5xx, `ModelAnomalyDetectionRail` | — | нет | AGE-20 |

## Что ограничения shell не останавливают

Проверено `evaluation/check_limits.py`:

- `shell_allowlist` проверяет только начало команды: `echo x; id` выполняется.
- `cat ../task.json` читается: относительный путь наверх проходит.
- Python может менять файлы внутри папки, в том числе тесты.
- Заблокированы: `curl`, `rm`, абсолютные пути наружу, чтение и запись наружу через файловые инструменты.

Настоящая изоляция — контейнер организаторов. Для ответа это не страшно: в финальном `task.json` нет `expected`, тесты восстанавливаются.

## Открытые риски для всей команды

Обновлено после новых ответов организаторов; подробности в `strategy.md`.

- Дедлайн 13 ноября, а план команды рассчитан на 19-е.
- Выбор задач становится одной из главных работ: организаторы ожидают, что решить реально около 30%.
- Поиск невыполнимых задач до вызова модели пока ни за кем не закреплён. Он нужен только для экономии токенов: штрафа за неверный ответ нет.
- Результаты на примерах могут быть оптимистичны: финальные задачи заметно отличаются.
