# Проверка по экспорту чата и регламенту, 14 ноября 2026

Проверены `ChatExport_2026-11-14 (1)/messages.html`, оба вложенных экземпляра `Регламент соревнования.md`, памятка участника и `task-dir.zip`. Для противоречивых пунктов использованы более поздние ответы организаторов в чате. Проверяется ветка `work/quality-minilm`, коммит `d63710d` плюс исправления изоляции unit tests этого аудита.

| Требование | Итог и основание |
|---|---|
| Код до 13 ноября 23:59 МСК; ссылка на репозиторий отправлена оргкомитету | Срок подтверждён сообщениями 797 и 836. Пользователь подтвердил, что письмо отправлено. GitHub показывает публичный репозиторий, поэтому отдельный доступ `promsoft` и `madrugado` не требуется. **До слияния PR основной `main` остаётся старым**; проверять нужно именно коммит выбранной ветки. |
| openJiuwen обязателен | `requirements.lock` фиксирует `openjiuwen==0.1.19`; `runtime/oj_agent.py` создаёт `ReActAgent` и инструменты OJ. Обязательность подтверждена сообщением 493. |
| Разрешённые модели и сеть | `run_agent.py` выбирает `qwen3.8-27b-noreason`, одну из четырёх разрешённых. В runtime нет загрузки весов или явных обращений к внешним адресам. Доступ к API задаётся только `LLM_BASE_URL` и `LLM_API_KEY`. |
| CPU энкодер | Буквальный текст регламента запрещает локальные нейросети, но более поздние сообщения 557, 719, 724 и 729 разрешают CPU энкодеры и уточняют запрет GPU. MiniLM хранится в образе как неиспользуемый запасной режим; основной предиктор — классический CatBoost. |
| `BUDGET` | В сообщениях 819–821 организатор подтвердил переменную окружения, значение может отличаться от 100000. `run_agent.py` читает её; при отсутствии использует 100000. Глобальное прекращение по локальной оценке отключено без `ENFORCE_BUDGET=1`; лимит контролирует прокси. |
| `OUT` и ответы | Организатор уточнил в сообщении 427, что `OUT` не используется. `run_agent.py --tasks-dir /data/tasks` читает каталог задач; `runtime/tasks.py` атомарно пишет `answer.txt` рядом с `task.json` после решения и не пишет его при статусе `impossible`. |
| Формат задач и скрытые ответы | Вложенный `task-dir.zip` содержит восемь задач с `task_type`, `instruction`, `reward`, `workspace`; загрузчик использует эти поля. Итоговый `expected` будет удалён (сообщение 493); загрузчик и предиктор его не используют. В пробном образе отсутствуют каталоги с эталонами. |
| Лимиты размера и времени | Суммарный размер отслеживаемых файлов — около 35,8 МБ при лимите 100 МБ. Образ `hack:latest` — 508 988 826 байт при лимите 4 ГБ. Чистая сборка без Docker cache успешно завершилась примерно за пять минут при лимите 1000 секунд. Агент ограничивает своё время 3300 секундами при внешнем лимите один час. |
| Запуск и тесты | `evaluation.run_image` запустил `hack:latest` с конкурсными Docker ограничениями на двух задачах без реального прокси; код выхода 0, обе задачи обработаны, предиктор `catboost_large` загрузился. Mock возвращает заготовленные ответы, поэтому его баллы не показывают качество решения. 42 unit tests в образе прошли. Предыдущий реальный прогон того же предиктора на 200 задачах дал 641 балл при локальной отсечке 50000. |
| Секреты | `.env` исключён из Git и Docker context; в образе нет `LLM_API_KEY`. Проверка отслеживаемых файлов не нашла ключей формата `sk-...`. `run_agent.py` удаляет ключ из окружения перед запуском инструментов агента. |

**Остаётся подтвердить:** открытый PR #10 с проверенной версией ещё не слит в `main`. У организаторов нет публичной копии двух скрытых отборочных задач и их прокси, поэтому исход отборочного прогона нельзя гарантировать локальными тестами. Автоматическая проверка безопасности жюри также не воспроизводится полностью.
