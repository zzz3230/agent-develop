# 200 задач, бюджет 50 000: предикторы и рюкзак

Один полный прогон каждого обученного варианта. Одинаковые 200 задач оценочной части planner-500: по 50 каждого типа, 40 невыполнимых, 160 выполнимых, максимум 852 балла. Награды 1–10 назначены независимо от содержимого. Модель qwen3.8-27b-noreason, alpha 1, повторные попытки выключены; решатель, инструменты и лимиты попыток одинаковые.

Основной результат — только проверенные ответы с завершением попытки до пересечения 50 000 списанных взвешенных токенов (вход / 10 + выход). Ответ ровно на границе учитывается. Монитор может остановить контейнер после последнего запроса с небольшим превышением: поэтому отдельно сохранены полный результат и фактический расход.

Выбран MiniLM + признаки: 459 баллов. С тем же предиктором рюкзак получил 447 баллов до границы; правильных решений: 61. Разница рюкзак минус жадный: -12 баллов (-2.6%). Фактический расход рюкзака 50031.9, время 21.3 мин.

Рюкзак использует reward × p и прогнозируемую стоимость; он перестраивает план после попыток. Параметры alpha и моделей на этих 200 задачах не подбирались. Выбор лучшего предиктора и сравнение политик выполнены на одной выборке: результат выбора может быть оптимистичен. Один прогон не устанавливает устойчивого превосходства.

Набор исправлен до запуска сравнения: дополнительная математическая цель q + offset теперь видна агенту. Старый остановленный прогон на 500 задачах не используется ни для обучения, ни для выбора победителя. Коэффициенты всех моделей обучены заранее и не менялись.

Дополнительная исходная очередь прервалась при сбое Docker/WSL на 30692.2 токена и исключена. Неудачная параллельная подготовка BGE без признаков не сделала ни одного LLM-вызова. После восстановления Docker оставшиеся полноценные прогоны шли последовательно. Завершённые обученные варианты не перезапускались. Аварийные расходы сохранены отдельно.

Входы и эталоны отделены: в контейнер попадает только input. Разбиение по исходным семействам не доказывает семантической независимости, а сами gaps/tricks уже известны команде. Это диагностическая оценка планирования при дефиците бюджета, не прогноз закрытого конкурса.

Протокол, хеш входов/моделей, расход каждого варианта и подробности планирования — в results.json. Сырые журналы: benchmark-runs/pool200-budget50000 (исключены из Git). Воспроизведение: подготовить исправленную eval-нагрузку на 200 задач с seed 101/1001, собрать образ с предикторами и выполнить `python -m evaluation.compare_pool_predictors`. По умолчанию агент и планировщик не переключаются на победителя автоматически.
Первый план рюкзака: 81 из 200 задач, построение 0.119009 с.

Первые 73 задач выбраны в одинаковом порядке; пересечение выбранных задач — 87. Баллы на общих задачах: жадный 450, рюкзак 447; дополнительные баллы на остальных задачах: 9 и 0. Поэтому разницу одного прогона нельзя полностью приписать политике: ответы модели и фактическая стоимость попыток также различаются.
