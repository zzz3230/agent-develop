# CatBoost на качественной выборке

Проверка 13 ноября 2026. Источники: diverse-v1, gaps-v1, tricks-v1. В `tricks-v1` уже есть 28 задач с ошибками, опечатками, отрицаниями, инъекциями в данных и сложным кодом. Из них 18 входят в 88 обучающих примеров, остальные оставлены в отложенной части. Обучающие и отложенные группы не пересекаются.

CatBoost 1.2.10 обучен на тех же 88 измеренных попытках, что и MiniLM. Выбор одной из трёх небольших конфигураций сделан только пятичастной групповой проверкой на обучении. Отложенные 44 задачи использованы один раз для оценки, без подгонки. API не вызывался; это проверка прогноза, не итоговый прогон агента на бюджет.

| Модель | Признаков | Brier на 44 | Ошибка цены, токены | Диапазон p |
|---|---:|---:|---:|---:|
| Постоянный прогноз из обучающей выборки | — | 0.22676 | 493.83 | — |
| MiniLM + признаки без ключевых слов | 402 | 0.22675 | 470.62 | 0.834–0.847 |
| MiniLM + признаки с ключевыми словами | 429 | 0.22670 | 470.43 | 0.834–0.847 |
| **CatBoost, только признаки без ключевых слов** | **18** | **0.22175** | **457.16** | **0.689–0.839** |
| CatBoost, признаки с ключевыми словами | 45 | 0.22820 | 457.17 | 0.759–0.908 |
| CatBoost, MiniLM + признаки без ключевых слов | 402 | 0.22584 | 465.91 | 0.719–0.906 |

**Вывод:** самый простой CatBoost улучшил обе метрики относительно текущего MiniLM на этих 44 примерах, но выигрыш по Brier мал: около 0.005. Вариант с эмбеддингами проиграл простому CatBoost. Пока рано менять очередь: требуется сравнение очков в одинаковом бюджете, а 44 примера слишком мало для уверенного выбора. После просмотра отложенных метрик нельзя подбирать другие параметры на этих же 44 задачах и выдавать результат за независимый.

**Следующий шаг для данных:** создать новые *семейства* с опечатками, отсутствующими полями, конфликтующими сведениями и похожими, но решаемыми случаями. Их нужно разметить реальным запуском агента, сохранить фактическую цену и правильность; копирование существующей задачи с другим именем не создаёт нового независимого примера. До такого запуска новые синтетические задачи не следует добавлять в обучение с выдуманной меткой.

## Более крупная ретроспективная оценка

По запросу проверены сохранённые попытки на прежнем пуле из 200 задач. Из семи наших прогонов получено **107 разных задач с фактической попыткой, 538 попыток всего**. У неисполненных задач нет измеренной цены и исхода; они исключены. Повторы одной задачи усреднены перед расчётом ошибок. Для контроля отдельно проверены четыре прогона из обновлённого `main`: **97 разных задач, 381 попытка**. Эти данные использованы только для оценки и не добавлены в обучение.

Это подтверждает направление на большем числе *наблюдаемых* задач, но не является независимым отложенным тестом: пул собран из известных семейств, а планировщики чаще запускали выгодные по своим оценкам задачи. Сравнение показывает ошибку предсказаний на реально исполненных задачах, не очки от работы агента с CatBoost. Конкурсный режим не менялся.

Машинные результаты: `catboost-pool200-local.json` и `catboost-pool200.json`. Скрипт: `python -m evaluation.evaluate_catboost_pool` (семь локальных прогонов); для четырёх прогонов обновлённого `main` передать `--reports-dir` с путём к опубликованным JSON.

## CatBoost + сжатый MiniLM

Дополнительно проверено PCA-сжатие эмбеддинга MiniLM до 8, 16 и 32 компонент. PCA в каждом из пяти обучающих фолдов обучается только на его train-части. Глубина дерева и остальные настройки зафиксированы по прежнему лучшему простому CatBoost; выбор размера сделан по Brier на обучении. Отложенные 44 задачи использованы только для диагностической оценки.

| Компонент MiniLM | Brier на train CV ↓ | Brier на holdout ↓ | Ошибка стоимости на holdout ↓ |
|---:|---:|---:|---:|
| **0, без энкодера** | **0.14641** | **0.22175** | 457 |
| 8 | 0.15197 | 0.23972 | **453** |
| 16 | 0.15230 | 0.23902 | 467 |
| 32 | 0.14912 | 0.23520 | 492 |

Ни один размер не улучшил вероятность успеха. Вариант с 8 компонентами уменьшил ошибку стоимости всего на ~4 токена при заметном ухудшении Brier. Поэтому энкодер для CatBoost пока не рекомендован; исходные 384 компоненты ранее также не помогли. Числа для всех размеров на holdout являются исследовательскими: подбирать по ним новый размер и снова считать эту же выборку независимой нельзя.

Код и полные результаты: `evaluation/try_catboost_pca.py`, `catboost-pca.json`.

Полные конфигурации и результаты: `catboost-trial.json`. Воспроизведение: `python -m evaluation.try_catboost_quality` в окружении с CatBoost 1.2.10, scikit-learn и зависимостями из `evaluation/predictor-training-requirements.txt`.
