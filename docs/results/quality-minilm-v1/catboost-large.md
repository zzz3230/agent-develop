# CatBoost на расширенной выборке

13 ноября 2026. Обучена отдельная модель `catboost_large` на 301 **реальной попытке агента**. Взяты 88 исходных задач из `quality-minilm/train` и 213 вариантов из `planner-500/train`. Дополнительные задачи представляют 59 семейств; всего в обучении 108 семейств. Группы, оставленные для проверки `quality-minilm/holdout`, исключены из новых задач. Все 213 задач были запущены через прокси, с настоящим расходом токенов и проверкой ответа; суммарный расход новых прогонов — 108 795,5 взвешенных токена. После сбоя Docker последние семь задач третьего пакета запущены отдельно; исходные 64 метки сохранены.

Вход модели — 18 простых признаков задачи и видимых файлов, без списка ключевых слов и без энкодера. CatBoost обучает два набора деревьев: вероятность правильного решения и ожидаемую стоимость. Выбор из трёх конфигураций сделан по пятифолдовой проверке с разделением по семействам.

| Метрика | Старый CatBoost, 88 примеров | Новый CatBoost, 301 пример |
|---|---:|---:|
| Brier, 44 отложенные задачи (меньше лучше) | 0,22175 | **0,22031** |
| MAE стоимости, 44 задачи (меньше лучше) | 457 | **439** |
| Spearman стоимости, 44 задачи (больше лучше) | **0,288** | 0,274 |

На обучающих 301 примере групповая кросс-проверка дала Brier 0,2001, MAE 282,6 токена и Spearman 0,464. Средняя стоимость задачи там 552,7 токена; относительная MAE составляет **51,1%**. На отложенных задачах средняя стоимость 722,9 токена, MAE 439,1, то есть **60,7%** от средней стоимости. Постоянный прогноз среднего расхода на отложенных задачах даёт MAE 506,4 токена. Ошибка по-прежнему велика для точного планирования бюджета.

В выборке 224 успешные попытки из 301 (74,4%). Организаторы ожидают существенно меньшую долю решаемых задач на конкурсе, поэтому калибровка вероятности успеха здесь не может считаться конкурсной. Варианты внутри одного семейства похожи, а отложенные 44 задачи уже использовались в предыдущих экспериментах; оценка на них диагностическая, не новая слепая проверка. Специальных новых примеров с опечатками в расширение пока не добавлено: 213 новых меток относятся к существующим семействам `diverse` и `suite`.

В отдельном сравнении очереди на 200 задачах и бюджете 50 000 старый CatBoost дал 570 баллов для `reward/cost`, 558 для `reward×p/cost`, 555 для `reward/cost` вместе с предварительной проверкой. Каждый вариант запущен **один раз**, а первые 98 задач у очередей почти совпадали. Разницу в баллах нельзя уверенно приписать формуле; это скорее основание продолжать проверку стоимости и порядка задач. Подробности: [catboost-policy-200.md](catboost-policy-200.md).

Новый предиктор доступен через `PREDICTOR=catboost_large` в образе с CatBoost. По умолчанию он не включён: выигрыш по абсолютной ошибке небольшой, а ранжирование по расходу стало немного хуже. Для выбора конкурсного режима нужен свежий набор более трудных семейств и повторное сравнение итоговых баллов.

Машинные результаты: `catboost-large-training.json`. Код: `evaluation/collect_large_quality.py`, `evaluation/train_catboost_large.py`; модели: `predictors/catboost_large_success.cbm`, `predictors/catboost_large_cost.cbm`. Сырые журналы и входы находятся в игнорируемом Git каталоге `benchmark-runs/quality-large-v1/`; для воспроизведения сбора нужны тестовые корпуса и доступ к прокси.
