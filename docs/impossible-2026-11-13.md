# Дешёвое распознавание невыполнимых задач (2026-11-13)

## Проблема

В ночном прогоне невыполнимая задача стоила примерно как три выполнимые. Замер базовой версии на двух наборах по 60 задач
(в каждом 12 невыполнимых): невыполнимая в среднем 1126 единиц, выполнимая 628. Баллов невыполнимая не приносит никогда,
поэтому всё, что на неё потрачено, — чистый убыток бюджета.

По журналам модель видит пробел уже за 1–2 вызова (файла нет, человека нет, курса валюты нет), но не верит себе и дальше:
ищет скрытые файлы и метаданные (`find -name ".*"`, `stat`, `md5sum`, `cat -A`), выходит за пределы каталога, повторяет
те же команды, а в задачах на код подделывает типы (`class X(str)`, `import builtins`, `metaclass`), чтобы пройти
противоречивые тесты. Отдельная утечка — отказы allowlist: OpenJiuwen смотрит только первое слово, и `ls; head x`
отклоняется как команда `ls;`; на это уходило 12–13 шагов на 60 задач.

## Что сделано

Все изменения включаются флагами; в Dockerfile они теперь включены по умолчанию.

| Флаг | Файл | Что делает |
|---|---|---|
| `IMPOSSIBLE_RULES=1` | `runtime/profiles.py` | В системную инструкцию добавлены правила: проверить очевидный вариант один раз; не искать скрытые файлы, метаданные и данные снаружи; не перебирать; пустая выборка или нулевая сумма — это ответ, а не пробел. Для кода — отдельные правила про противоречивые тесты. |
| `IMPOSSIBLE_NUDGE=1` | `runtime/attempt_rail.py` | После вызова инструмента проверяются признаки поиска отсутствующих данных: `outside`, `hidden_data_hunt`, `nothing_found`, `missing`, `repeated_output`, у кода — `test_hack`. При первом признаке (или когда остаётся последний оплаченный вызов) в ответ инструмента один раз дописывается подсказка «если данных нет — ответь IMPOSSIBLE». Если после подсказки снова видно `outside` или `hidden_data_hunt`, попытка останавливается (`gap_confirmed`). `test_hack` останавливает попытку сразу. |
| `SHELL_FIX=1` | `runtime/attempt_rail.py`, `runtime/oj_agent.py` | `ls;` превращается в `ls ;`, в allowlist добавлены `cd awk sed uniq tr comm printf`. |
| `PRECHECK=1` | `runtime/precheck.py`, `run_agent.py` | До первого вызова модели, без модели и без эталонов, к вопросу дописываются факты о файлах: названного файла или каталога нет (и какой есть рядом); имени из вопроса нет ни в одном файле (и ближайшее похожее: Sergie → Sergei); имя — заголовок двух файлов (тёзки); значения ключа одной таблицы отсутствуют в другой (GBP нет в rates.csv); ключ повторяется (order_id 17 в двух строках, Alex Lee дважды в customers.csv). Агент получает факты, а не вердикт: опечатка в вопросе остаётся решаемой. |

`test_hack` — это код, который подменяет типы или тесты: `__instancecheck__`, `import builtins`, `metaclass=`,
`class X(int|str|float|bool|bytes)`, `import unittest`, `sys.modules`, `__class__ =`. Во всех журналах этой сессии
(train60, eval60, pool200, coding30, все версии) такой код ни разу не встретился в выполнимой задаче.

## Результаты

Модель qwen3.8-27b-noreason, локальный прокси, бюджет 100000 (без лимита) или 50000 с `ENFORCE_BUDGET=1` для pool200.
Версии: base — проект как пришёл; r1 — только правила; r2 — правила, подсказка и SHELL_FIX; r3 — то же с уточнёнными
правилами; r4 — r3 и PRECHECK; r5 — r4 и `test_hack` (сначала подсказка, остановка на втором); r6 — `test_hack`
останавливает сразу (итоговая версия).

## Ограничения

- Шум прогона большой: одна и та же версия на тех же 60 задачах даёт ±15–30 баллов, отдельная задача — до ×3 по цене
  (например, p0345 в eval60: 193 в r3 и 1078 в r4 без единого изменения, которое её касается). Поэтому вывод делается
  по расходу на невыполнимые, который снижается во всех парах, а баллы — «в пределах шума, без потерь».
- Не покрыт фактами PRECHECK поиск через цепочку (сотрудник → компания → штаб-квартира, когда у компании нет адреса):
  его по-прежнему ловит только подсказка, в среднем ~600 единиц.
- Каждый вариант прогнан один раз. Для финального решения стоит повторить r6 на pool200 2–3 раза.

## Как проверить

```bash
python -m unittest evaluation.test_impossible_guards
python -m evaluation.report_impossible base=docs/results/2026-11-13-impossible/base-train60.json r5=docs/results/2026-11-13-impossible/r5-train60.json
```

Полные таблицы всех версий — `docs/results/2026-11-13-impossible/summary.txt`, оценённые прогоны — JSON рядом.
Отключить любое изменение можно через `-e FLAG=0` при запуске образа.
